📋 Official Embedded Timeline Setup
1. Nothing to register

Enter a public X handle or profile URL above and press Enter. The default is @I_Am_The_ICT. X loads the public profile timeline inside its own secure iframe.

2. Posts and replies

The widget requests profile replies where X supports them. Use the ↗ toolbar button to open the account’s full “Posts & replies” page on X.

3. Saved preferences

The selected handle and light/dark theme are cached in this browser’s localStorage. No credentials are stored because this mode uses none.

⚠️ Limitations of the 100% free mode

X renders the timeline in a cross-origin iframe and intentionally does not expose its post data to this page. Therefore this version cannot reliably classify a post as new/thread/reply, cache individual posts, filter or export them, attach notes/statuses, or store tweet rows in Google Sheets. X also controls the ordering, availability, and number of posts shown.

Those structured tracking features require a data API and a server-side proxy. The current official X API is pay-per-use, and third-party APIs are also metered after their trial credit. They have intentionally been removed from this free-only build instead of presenting a broken or misleading setup.
