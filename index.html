📋 Setup & Data Sources
⚠️ X/Twitter's official API no longer offers free read access (free tier is write-only). This dashboard uses twitterapi.io — a cheap pay-per-use proxy (~$0.15 per 1,000 posts, new accounts get free trial credit, no card required) which is effectively free for tracking a single account's timeline. All requests run directly from your browser using your own key. Data is cached in localStorage and can optionally sync to your own Google Sheet.
Get a key: 1) go to twitterapi.io → 2) sign in with Google (no card, no OAuth dance) → 3) copy your API key from the dashboard → 4) paste it above.
If the browser blocks direct calls (CORS), requests are retried through this prefix + URL-encoded target. Leave empty to call twitterapi.io directly. If both fail, use 📋 Manual JSON Import instead (paste a response from Postman/curl).
☁️ Google Sheets Sync (cross-device, optional)
1. Go to console.cloud.google.com, enable the Google Sheets API, configure the OAuth consent screen (add yourself as a Test user), then create an OAuth 2.0 Client ID (Web application) with authorized JavaScript origins https://daggerok.github.io and http://localhost.
2. Paste the Client ID + a Spreadsheet ID (or URL) below. Each tracked handle gets its own tab, e.g. TW-@I_Am_The_ICT. Only the Client ID is stored — no secrets. The access token lives in memory only.
